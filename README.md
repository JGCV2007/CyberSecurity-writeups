## 📝 Modelo de cada write-up

1. **Objetivo:** o que o laboratório propõe
2. **Ferramentas:** Nmap, Burp Suite, Wireshark etc.
3. **Passo a passo:** comandos e raciocínio, com prints
4. **Resultado:** o que foi encontrado ou resolvido
5. **Mitigação:** como corrigir ou prevenir a falha
6. **Aprendizados:** o que levo para os próximos labs
